# First Sword リマスター 設計書（ゲームプランナー）

## 1. 目指す体験
「**見て、弾いて、崩して、斬る**」。敵の攻撃を読み、ジャストで弾く気持ちよさを中心にした1対1の剣戟アクション。

| 柱 | 内容 |
|---|---|
| 読める | 敵の攻撃は「予備動作 → 攻撃判定 → 硬直」に分かれ、予備動作中は武器が光る。弾ける瞬間は白い閃光で予告する |
| 報われる | ジャストパリィは「ヒットストップ + スロー + 火花 + 画面揺れ + 効果音 + PARRY 表示」で大きく褒める |
| 選べる | パリィ（高リターン・失敗で被弾）／ガード（安全・スタミナ消費）／回避（無敵・スタミナ消費）のリスクとリターンを分ける |
| 分かる | 体力・スタミナ・敵の体幹・スキルのクールダウン・操作ガイドを常に画面に表示する |

## 2. 戦闘ルール
### 2.1 敵の攻撃フェーズ（アニメーション進行率）
| フェーズ | 範囲 | 内容 |
|---|---|---|
| 予備動作 | 0.00 – 0.40 | 武器が段々光る。プレイヤーの方を向き続ける |
| 予告閃光 | 0.32 | 白い閃光エフェクトと効果音（パリィの合図） |
| 攻撃判定 | 0.40 – 0.70 | 武器の当たり判定を有効化 |
| 硬直 | 0.70 – 1.00 | 判定なし。反撃のチャンス |

ボスは攻撃の 25% が「**弾けない攻撃**」（赤い閃光）。回避で対応する。

### 2.2 パリィ／ガード
| 項目 | 値 | 意図 |
|---|---|---|
| ジャストパリィ受付 | 押してから 0.18 秒 | 少し甘めにして「狙えば取れる」 |
| ガード | パリィボタン押しっぱなし | 被ダメージ 25%、スタミナ 20 消費 |
| パリィ成功 | ダメージ 0、敵の体幹 +35、敵は 0.6 秒よろめく | 攻めに転じる時間を与える |
| パリィの連打対策 | 受付終了後 0.35 秒は再受付不可 | 連打で取れないようにする |
| スタミナ 0 でのガード | ガード崩し（0.8 秒動けない） | 守り続けるリスク |

### 2.3 体幹（ポスチャー）
- 敵ごとに体幹ゲージ（最大 100）を持つ
- 増える量：パリィ +35、通常攻撃ヒット +6
- 2 秒攻撃を受けないと毎秒 10 回復する
- 満タンで「**体幹崩し**」：2.5 秒スタン、被ダメージ 2.5 倍。`BREAK!` を表示する

### 2.4 スタミナ（プレイヤー）
| 行動 | 消費 |
|---|---|
| 回避 | 25 |
| ガードで受ける | 20 |
| 回復 | 毎秒 30（行動後 0.6 秒は回復しない） |

最大 100。不足していると回避できない（ゲージが赤く点滅して知らせる）。

### 2.5 手応え（ヒットストップ・スロー・揺れ）
| 事象 | ヒットストップ | スロー | カメラ揺れ |
|---|---|---|---|
| 通常攻撃ヒット | 0.045 秒 | - | 弱 |
| コンボ最終段ヒット | 0.09 秒 | - | 中 |
| 被弾 | 0.07 秒 | - | 中 |
| ガード | 0.05 秒 | - | 弱 |
| ジャストパリィ | 0.12 秒 | 0.3 倍 × 0.35 秒 | 強 |
| 体幹崩し | 0.15 秒 | 0.25 倍 × 0.6 秒 | 強 |
| 撃破 | 0.2 秒 | 0.2 倍 × 1.0 秒 | 強 |

## 3. エフェクト（自作パーティクル。Effekseer は使わない）
HDR で発光させ、ブルームに乗せる。テクスチャは使わず形状をシェーダーで作る（画風を統一するため）。

| 名前 | 構成 |
|---|---|
| HitSpark | 速度方向に伸びる火花 24 個 + 閃光 + 衝撃リング |
| ParryFlash | 青白い大閃光 + 二重リング + 火花 48 個 |
| GuardSpark | 小さな火花 12 個（橙） |
| Telegraph | 武器位置に十字の閃光（通常：白、弾けない攻撃：赤） |
| SwordTrail | 剣の軌跡リボン（プレイヤー：青白、敵：武器色） |
| DodgeDust | 足元の砂煙 |
| SkillWind / SkillFire | 竜巻状の粒子／火の粉と炎 |
| Break / Death | 大きなリングと上昇する光の粒 |

## 4. UI（HUD）

### 見た目の方針（`Source/Application/UI/UiTheme.cpp`）
- 世界観は「月夜の剣戟」。象牙色の文字、金の細線、深紅の体力、菱形のモチーフ
- 書体は欧文が Cinzel（碑文体）、和文がしっぽり明朝。小さいボタン表記だけ Noto Sans JP
- 配置は、自分=左上、敵の体力と体幹=下中央、スキル=右下、操作=左下
- 操作ガイドは開始直後と入力機器を持ち替えた時だけ出し、10 秒で消える
- ボタン表記は、最後に使った機器（キーマウ / パッド）に全画面で合わせる
- 弾ける攻撃は白い菱形、弾けない攻撃は朱の「危」。色だけでなく形でも区別する
```
┌──────────────────────────────────────────────┐
│            [敵の名前]                         │
│            ████████████░░░  体力             │
│              ▓▓▓▓▓░░░░░    体幹              │
│                                              │
│                  (PARRY! / BREAK!)           │
│         ダメージ数値が浮かぶ                  │
│ ████████████  HP                  [Q] [E]    │
│ ▓▓▓▓▓▓▓▓      STAMINA       操作ガイド       │
└──────────────────────────────────────────────┘
```
- 被ダメージ時は画面端が赤く脈打つ。体力 30% 以下で常時うっすら赤くする
- 操作ガイドは右下に常時表示。チュートリアル中は今やるべき操作を強調する

## 5. チュートリアルステージ
練習用の木人（攻撃が遅く、弾ける攻撃だけをする敵）を相手に、1 つずつ覚える。

| # | 課題 | 達成条件 |
|---|---|---|
| 1 | 移動 | 2 秒間移動する |
| 2 | カメラ | マウス／右スティックで見回す |
| 3 | 攻撃 | 木人に 3 回当てる |
| 4 | 回避 | 2 回回避する |
| 5 | ガード | 木人の攻撃をガードで 1 回受ける |
| 6 | パリィ | ジャストパリィを 2 回成功させる |
| 7 | 体幹崩し | 体幹を満タンにして崩す |
| 8 | スキル | Q と E を 1 回ずつ使う |
| 9 | 卒業 | 木人を倒す → ステージ選択へ |

ステージ選択画面から入れる。`--scene 5` で直接起動できる。

## 6. 操作
| 操作 | キーボード / マウス | パッド |
|---|---|---|
| 移動 | WASD | 左スティック |
| カメラ | マウス | 右スティック |
| 攻撃 | 左クリック | R2 |
| パリィ / ガード（長押し） | 右クリック / C | L2 |
| 回避 | Shift | A |
| スキル | Q / E | L1 / R1 |
| ロックオン | Tab / ホイールクリック | R3 |

ロックオン中は、カメラが敵を画面に入れ続ける。攻撃の振り始めには敵の方を向く。

## 7. 品質の確認方法
- `bash Tools/build_test.sh`：Debug と Release のビルド、全シーンのスモークテスト（自動入力での戦闘を含む）、戦闘ルールの単体テストを実行する
- スクリーンショットは `Document/test/` に保存される
